# 1.0.10 构建与验证记录（2026-11-24）

## 变更

- 修复应用内升级卡在 92%。真实设备日志确认了三个原因：升级脚本使用了不存在的 `$APP_DIR/cmd/main`（无法停/启应用）；`appcenter-cli install-fpk` 返回 0 但没有替换正在运行的二进制；兜底 `cp` 覆盖运行中的可执行文件报 `Text file busy`。
- 程序升级改为应用内完成：下载 `.fpk` 后校验 SHA-256 / manifest 版本 / `app.tgz` MD5 / ELF 架构，暂存并备份，再用“临时文件 + rename”原子替换，最后 `syscall.Exec` 原地重启；失败自动回滚，启动时按版本号自愈。不再调用 `appcenter-cli`、`install-fpk` 或 `cmd/main`。
- 新增独立“内核升级”通道：从上游 GitHub `anefzaoui/misterdownloadmanager` 最新 Release 获取 `-linux-x86_64.tar.gz` 与 `SHA256SUMS.txt`，校验后只替换两个引擎二进制，写 `mdm/engine-version`，重启引擎并等待就绪，失败回滚。程序升级不再包含引擎二进制，避免内核被降级。
- 新增下载记录：`history.json` 持久化最近 500 条任务，界面顶部“记录”可查看名字、状态、大小、目录、添加时间，支持“再次下载”和清空。
- 删除任务改为两个选项：**删除下载**（暂停后移出列表，保留磁盘文件）与 **无痕删除**（暂停后连文件、`*.mdm.part`、`*.mdm.json`、`*.mdm.pieces` 一并清除，并彻底删除下载记录）。

## 本地实测

| 场景 | 结果 |
| --- | --- |
| 删除下载（下载中） | 先暂停再移除；任务消失，2GB 未完成文件保留，记录状态为“已删除” |
| 无痕删除（下载中） | 任务、`name.mdm.part`、`name.mdm.json` 全部清除；同目录下其他任务的文件不受影响；记录被彻底移除 |
| 删除弹窗 | 含“删除下载 / 无痕删除”两项说明与三个按钮，取消不执行任何操作 |
| 下载记录 | 4 条不同状态记录正确显示，重启服务后仍保留；再次下载会带入原链接 |
| 内核升级通道 | 完成下载、SHA-256 校验与 ELF x86-64 检查（本机不具备 Linux 引擎替换条件） |
| 程序升级 | 单元测试覆盖暂存/备份/替换/回滚；原子 rename 与 `syscall.Exec` 代码路径通过编译与静态检查 |

`gofmt -l`、`go vet ./...`、`go test ./...` 通过；`tools/validate-fpk.py` 全部 PASS（新增双选项删除、记录、双通道升级、无 `appcenter-cli` 检查）。
