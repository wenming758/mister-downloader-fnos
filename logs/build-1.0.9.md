# 1.0.9 构建与验证记录（2026-11-24）

## 变更

- 原生面板顶部新增“刷新”按钮：立即重新拉取任务列表与下载进度，用于查看其他设备新增的任务；刷新期间图标旋转、按钮禁用，结束后提示任务数与等待获取种子的数量。
- 刷新走 `pollTasks(true)`，即使正处于轮询中或页面不可见也会强制请求；引擎未就绪时明确提示“刷新失败：下载引擎未就绪”，不再误报刷新成功。
- 安装/升级脚本只修正数据目录顶层属主，去掉递归 `chown -R`：大容量下载目录会让应用中心长时间停在最后一步（92%）。
- `cmd/install_callback` 记录安装开始/完成时间戳到 `server.log`，与应用中心安装阶段对照定位卡点。

## 本地实测

| 场景 | 结果 |
| --- | --- |
| 刷新按钮（引擎未启动） | 提示“刷新失败：下载引擎未就绪”（错误样式），按钮恢复可用、旋转取消 |
| 刷新按钮（正常任务列表） | 提示“已刷新：N 个任务，P 个等待种子” |
| 原生版视图刷新 | 重新加载上游 iframe 并提示“已刷新原生版面板” |
| `chown -R` 移除 | `install_callback`、`upgrade_callback` 均无递归 chown，校验脚本通过 |

`gofmt -l`、`go vet ./...`、`go test ./...` 通过；`tools/validate-fpk.py` 全部 PASS（新增“刷新按钮”检查）。
